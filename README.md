# Stellar Burgers - Автотесты

Проект содержит автотесты для веб-приложения Stellar Burgers.

## Структура проекта

- `src/main/java/ru/yandex/practicum/stellarburgers/` - основной код
  - `api/` - API клиент для работы с пользователями
  - `config/` - конфигурация (драйвер, настройки)
  - `pageobject/` - Page Object классы для всех страниц
- `src/test/java/ru/yandex/practicum/stellarburgers/tests/` - тесты
  - `BaseTest.java` - базовый класс для тестов с кроссбраузерностью
  - `RegistrationTest.java` - тесты регистрации
  - `LoginTest.java` - тесты входа
  - `NavigationTest.java` - тесты навигации
  - `LogoutTest.java` - тест выхода
  - `ConstructorTest.java` - тесты конструктора

## Требования

- Java 11
- Maven 3.6+
- Google Chrome
- Яндекс.Браузер (опционально)

## Запуск тестов

### Запуск всех тестов
```bash
mvn clean test
```

### Запуск с генерацией Allure отчета
```bash
mvn clean test
mvn allure:serve
```

### Запуск конкретного теста
```bash
mvn test -Dtest=RegistrationTest
```

## Кроссбраузерное тестирование

Тесты автоматически запускаются в двух браузерах:
- Google Chrome
- Яндекс.Браузер

Для Яндекс.Браузера путь к исполняемому файлу берется из переменной окружения `YANDEX_BROWSER_PATH` или используется путь по умолчанию.

## Allure отчеты

Для генерации Allure отчета:
1. Запустите тесты: `mvn clean test`
2. Откройте отчет: `mvn allure:serve`

Отчет будет доступен в браузере по адресу http://localhost:XXXX

## Структура тестов

### Регистрация
- Успешная регистрация нового пользователя
- Ошибка при регистрации с некорректным паролем (менее 6 символов)

### Вход
- Вход через кнопку "Войти в аккаунт" на главной странице
- Вход через кнопку "Личный кабинет" на главной странице
- Вход через кнопку "Войти" в форме регистрации
- Вход через кнопку "Войти" в форме восстановления пароля

### Навигация
- Переход в личный кабинет по клику на "Личный кабинет"
- Переход из личного кабинета в конструктор по клику на "Конструктор"
- Переход из личного кабинета в конструктор по клику на логотип

### Выход
- Выход из аккаунта по кнопке "Выйти" в личном кабинете

### Конструктор
- Переход к разделу "Булки"
- Переход к разделу "Соусы"
- Переход к разделу "Начинки"
